ScapeLite v0.3.0 is the first public release: optional, display-only plugins for Scapewatch (Steam, Windows).

**Install:** download `ScapeLite Setup 0.3.0.exe` below and run it. Windows may show an "unknown publisher" warning because the installer is not code-signed yet: choose **More info**, then **Run anyway**.

### Route Advisor
- Plan tab compares three paths, Skilling XP, Combat XP and Quests, scored in weighted levels per hour, with your current queue as the baseline.
- Teleport charges have a price and pick swaps have to earn their place; every swap explains itself (this pick vs yours, effect of that swap alone).
- Skill priorities (Vigor first by default) with profiles: Vigor and gear first, Even progress, Melee/Ranged/Magic gear first, Balanced, Vigor focus.
- Map slides out beside the panel, overlapping stops fan out, the panel is resizable, a calculating bar shows while it thinks.
- Persistent badge on the Tasks panel: yellow warning, then green with the saving, or "Route optimal". Click it to open the advisor.

### Bank
- Category separators with labels, category chips on item hover, hover sub-menus on the Raw / Processed / Equipment / Potions filters.
- Item size slider, new-item sparkle and NEW tag (also on the side-menu bank icon), Sort/Swap/Insert/Remove placeholders tucked into a Settings menu.

### Tooltips and panels
- Task and quest tooltips show a level-progress bar, duration and XP per hour.
- Skills panel: queued task XP as a green section on each skill bar, colour-graded bars, level-up line in the tooltip.
- Crafting Potential: the Smith / Craft / Imbue / Brew XP bar shows the level reachable with every material in your bank (collection items first), with a hover breakdown.
- Collapsible Current Task; smooth 1:1 panel dragging with edge snapping and a Fuse button; fuse no longer shoves the menu / HP dock off screen.
- Window buttons dock (move, resize, tuck away, lock, closes the World Map with the cross) and a movable food and potions panel; right-click any panel title bar for the lock menu.
- Floating windows (Float button on Settings, Bank, ...), layout presets, polished top-right buttons and tooltips.
- Windows notifications auto-dismiss.

### Combat, chat and reporting
- Combat Readout: HP and Spirit numbers, attack timer countdown, unrounded attacks per second and expected DPS on the combat screen.
- Chat remembers your last channel and starts on the leftmost shown one instead of always Global.
- Bank gear is grouped by style (melee / ranged / magic, weapons and equipment) and every separator can be collapsed; folds are remembered.
- Only the Status Indicator shows on the login / main menu screen.
- Anonymous usage count (on by default, asked in the first-launch setup, off in Settings): at most one request a day to GoatCounter with the page /active and the version (plus the IP and browser name every web request carries; GoatCounter does not store the IP). No name, character, game data, settings or webhooks. Inactive until a counter site is configured.
- In-game bug report (Settings, or the bug icon under the status light). Only Official plugins are fixed by the ScapeLite team.

### Settings and setup
- Plugin settings grouped (ScapeLite, Discord, Tasks and routes, Interface), quick-jump menu with flyouts, guides first, About on its own row.
- Chat relay ping roles editor: any number of roles, each with any categories.
- First-launch play style setup (combat style, teleports, combat vs skilling weight, notifications), re-runnable from Settings.

### Dashboard and website
- Game status banner, link to the website, live Dashboard button on the website.

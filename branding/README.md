# ScapeLite branding

The logo is a block-built gold pixel "S" on a dark rounded tile (`logo.svg`), with a wordmark lockup (`logo-lockup.svg`, "Scape" light, "Lite" gold). Palette: gold `#ffd24a` / deep gold `#b8760f` / highlight `#fff0b0` on `#23232f`.

`png/` holds raster exports (512, 256, 128, 64, 32, 16 px) of the icon.
